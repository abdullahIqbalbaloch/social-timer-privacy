Privacy Policy

How the Social Media Time Limiter Chrome Extension handles your data — clearly, honestly, and without jargon.

Effective: June 2025 Last updated: June 2025 Version 1.0
TL;DR — The short version

We collect nothing. Your data never leaves your device. No servers, no accounts, no tracking, no ads. Everything the extension stores stays inside your own browser.

01

Overview

Social Media Time Limiter ("the Extension") is a Chrome browser extension that helps users track and limit the time they spend on Facebook and Instagram. This Privacy Policy explains what data the Extension accesses, what it stores, and how it is used.

The Extension is operated by an independent developer and is not affiliated with Meta, Facebook, Instagram, or Google.

02

Data We Collect

We collect no personal data. The Extension does not collect, transmit, store on external servers, or share any personally identifiable information (PII) of any kind.

The only data the Extension stores is:

  • Your chosen daily time limit (e.g. "30 minutes") — stored locally in your browser
  • Your daily usage count in seconds — stored locally in your browser, reset each midnight
  • Whether the Extension is enabled or paused — stored locally in your browser

This data exists solely on your device using Chrome's built-in chrome.storage.local API. It is never transmitted anywhere.

03

Permissions Explained

The Extension requests the following Chrome permissions. Here is exactly why each one is needed:

Permission Why it's needed
tabs To detect when the active tab is on facebook.com or instagram.com so time tracking can begin. The Extension only reads the tab URL — no page content is accessed.
storage To save your time limit and daily usage count locally on your own device. Nothing is uploaded to any server.
notifications To send a browser notification when your daily time limit is reached.
alarms To run a background check every 10 seconds while the browser is open, so usage time is tracked accurately.
Host access to facebook.com, instagram.com To inject a visual overlay (red screen alert) directly onto these pages when the limit is exceeded. No content from these pages is read or transmitted.
04

Data Sharing

We do not share any data with any third party — because we do not collect any data to share.

  • No analytics services are used
  • No advertising networks are integrated
  • No external APIs are called
  • No usage statistics are sent to any server
05

Remote Code

The Extension does not use or load any remote code. All JavaScript is bundled locally within the Extension package. No code is fetched from external servers at runtime.

06

Children's Privacy

The Extension does not knowingly collect any data from any user, including children under the age of 13. Since no data is collected at all, this Extension is safe to use by users of any age.
